# alternativa-testa

## Aplikacije

### App1: Osebni zapiski (Personal Notes)
- Port: 5000
- Funkcije: več zapiskov, naslov + vsebina, pregled, urejanje, brisanje
- Uporabniški sistem: login/register
- Zagon: `python app1.py`

### App2: Preprosta socialna platforma (Simple Social Platform)
- Port: 5001
- Funkcije: objave (besedilo), slike, pregled objav drugih uporabnikov
- Uporabniški sistem: login/register
- Zagon: `python app2.py`

### App3: Task Manager
- Port: 5002
- Funkcije: naloge z naslovom, opisom, statusom (todo/doing/done), CRUD
- Zagon: `python app3.py`

## Zahteve
- Uporaba podatkovne baze (TinyDB)
- Uporaba session
- Sinhroni klici (Flask routes)
- Asinhroni klici (AJAX)
- Vsaj 2 aplikaciji imata uporabniški sistem

## Namestitev
- Flask in TinyDB sta že nameščena
- Zaženite posamezno aplikacijo z `python appX.py`
